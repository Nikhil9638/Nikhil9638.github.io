Velora 2 — QR-based café ordering platform

Customers scan the QR code on their table, order from the menu, and watch their order move to served. Staff and owners run service from their own dashboards.

Role
Sole developer, built end to end
Stack
React, Django REST Framework, PostgreSQL
Source
Private (commercial product)

For customers

  • Each table has its own QR code, so every order arrives tied to the right table.
  • Browse the menu by category or search it, then build a cart.
  • Submit the order and follow it live: Placed, Confirmed, Preparing, Ready, Served.

For staff

  • A separate staff login opens a dashboard built for service, not administration.
  • Incoming orders arrive on the staff dashboard as customers place them.
  • Staff take payment in person and mark the order as paid.

For owners

  • A separate owner login with full control of the café.
  • Manage menu items and categories, orders and payments, staff accounts, and tables with their QR codes.
  • Menu changes reach the live customer menu as soon as they are saved.

What's next

Stripe online payments and production deployment are the next milestones. Neither is live yet; today, customers pay staff in person.

Hunter System — gamified Python‑learning platform

Students learn Python through placement, lessons and quizzes, and progress through ranks as they clear topics. The server, not the browser, decides every score, rank and reward.

Stack
React, PHP, MariaDB (MySQL‑compatible)
Source
Public on GitHub
Demo
None; runs locally on XAMPP

A student's path

  1. Sign up Create an account and log in.
  2. Choose a level Pick one of four self-described experience levels.
  3. Placement test Ten questions set a starting rank and a recommended topic.
  4. Lessons and quizzes Read a topic's lesson, then pass its five-question quiz with 3 of 5.
  5. Rank up Clear topics to climb from E-Rank to S-Rank and earn Mana.
  6. Collect badges Spend Mana in the badge store and show badges on the profile.

Also in the code

  • An 18-topic curriculum in six skill groups, from Python basics to files and objects.
  • Mana balance and ledger history, with one-time rewards per topic.
  • Admin tools for course content, student progress and login activity, and an audit log.
  • Argon2id password hashing and login throttling.
  • PHP integration tests for authentication, assessment, quizzes, badges and admin.
